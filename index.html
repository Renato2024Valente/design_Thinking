Design Thinking com Emojis

Escutar · compreender · criar · testar · melhorar

Uma ideia de cada vez. Uma aprendizagem melhor. 😊

Use os rostinhos para ouvir os estudantes, descobrir dificuldades e construir soluções junto com a turma. Este aplicativo funciona localmente, sem conta e sem enviar os dados para um servidor.

🔒 Privacidade: os registros ficam neste navegador. Evite inserir informações pessoais sensíveis.
Etapas do projeto
✨ Dica para o professor
Não existe emoção errada. Use as respostas para ouvir, acolher e planejar intervenções — não para rotular estudantes.
Etapa 1 de 5 · Empatia

Como você está se sentindo? 😊

Vamos entender a experiência do estudante antes de escolher uma solução. Você pode registrar uma resposta individual ou uma percepção da turma.

💛 Escutar primeiro
Escolha o rostinho que mais combina com você hoje
A emoção é uma pista para conversar, não uma nota nem uma avaliação do aluno.
Os campos estudante e respostas são opcionais.
Etapa 2 de 5 · Definir

Qual problema vamos resolver? 🎯

Transforme as observações em um desafio claro, específico e possível de enfrentar.

🔎 Foco no problema
Uma boa pergunta começa com “Como poderíamos...” e abre espaço para várias soluções.
🧠 Lembrete

Evite definir o estudante como “o problema”. Descreva a habilidade que precisa de apoio, as barreiras e o contexto de aprendizagem.

Etapa 3 de 5 · Ideação

Vamos criar soluções! 💡

Primeiro, gere possibilidades sem julgar. Depois escolha uma ideia simples para experimentar.

🌱 Muitas ideias
Exemplos: jogo educativo, vídeo curto, atividade em dupla, robô, quiz, mapa mental, simulação.
🌟
Suas ideias aparecerão aqui

Adicione pelo menos uma possibilidade para registrar a sessão.

🤖 Quer usar uma IA para ampliar as ideias?

O aplicativo cria um comando pronto para você copiar no ChatGPT ou em outra IA. Ele não envia os dados automaticamente nem precisa de chave de API.

Etapa 4 de 5 · Prototipagem

Vamos construir uma versão simples 🧩

O protótipo não precisa estar perfeito. Ele precisa ser simples o bastante para testar a ideia e aprender com o resultado.

🛠 Mão na massa
✅ Protótipo rápido

Combine um prazo curto, prepare uma primeira versão e observe como as pessoas a utilizam. Não é necessário esperar que tudo esteja perfeito.

Etapa 5 de 5 · Testar

Funcionou para quem vai usar? 🚀

Teste com os estudantes, acolha opiniões e registre o que deve ser mantido ou melhorado.

🔁 Aprender e ajustar
Como o estudante se sentiu depois de experimentar?
🔄 Design Thinking é um ciclo

Se a solução não funcionar para todos, isso não é fracasso: é uma informação importante para voltar, ajustar e testar de novo.
